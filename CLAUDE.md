# Peak View Windows and Doors Website

## Project Goals
Build a premium, professional landing page for a Bend, Oregon windows and doors company. CCB licensed. 15 years of hands-on experience. Compete on quality and craftsmanship, not lowest price.

## Brand Voice
Plain, direct, no jargon. No sales-y corporate language. Sound like a real craftsman, not a marketing bot. Restrained. Editorial. Premium but accessible.

## Key Rules
- Always invoke the front-end design skill before any front-end code. No exceptions.
- Use the screenshot loop to compare work before/after changes.
- Do not push to GitHub until I explicitly say "commit this to GitHub."
- When working with animated elements, skip the screenshot loop (I'll tell you if it looks good).
- Reference brand assets at `/brand_assets/` when available.

## Deploy Workflow
Local development on localhost. GitHub push only on explicit approval. Vercel auto-deploys from GitHub.

## Design Direction
Think premium custom home builder aesthetic. Tight spacing. Clean typography. Real install photos. Restrained animations (or none). This is a $20k-$40k decision for homeowners. They want craftsman, not tech startup.
